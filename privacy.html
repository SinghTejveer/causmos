Privacy Policy

The Causmos poster · last updated 29 October 2026

"The Causmos poster" is a private tool that publishes The Causmos's own videos to its own YouTube channel. It is not offered to the public, and it is used only by the channel's owner.

What it accesses

Through the YouTube API Services, with the owner's permission, it uploads videos to the owner's channel and reads the channel's name to confirm which channel is connected. It does not read, collect or store data about any other person, viewer or channel.

What it keeps

It stores only the sign-in token Google issues, on the owner's own server, so that uploads can continue. It shares nothing with anyone else and sells nothing.

Revoking access

Access can be removed at any time from Google account permissions, after which the stored token stops working and is deleted.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
